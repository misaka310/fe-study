# 問題作成・選択肢品質ルール

この文書は `docs/SPEC.md` の「問題」要件を、問題作成・レビュー・自動検査へ落とし込むための運用ルールです。仕様の正本は `docs/SPEC.md` であり、この文書はその要件を弱めたり例外化したりしません。

## 対象

現在の演習問題は次の二つを同じ品質基準で扱います。

- 通常問題: `src/content/questions` の 217 問
- 基本問題: `src/content/basic` の 100 問
- 合計: 317 問

「基本問題だけ」「通常問題だけ」の部分監査を、全問題の品質確認として扱いません。

## 選択肢の必須ルール

1. **同じ回答種別にそろえる**
   - 結合方式を問うなら JOIN の候補同士、暗号方式を問うなら暗号方式同士、数値計算なら数値同士、プログラム追跡なら同じ返却値の型同士で比較させます。
   - 正答だけが文章、誤答だけが単語、正答だけが単位付きなど、見た目で正解を推測できる差を作りません。

2. **同じ論点・比較軸で迷える誤答にする**
   - 誤答は、学習者が条件の一部を取り違えたときに実際に選び得る候補にします。
   - 例: `LEFT OUTER JOIN` の問題なら `INNER JOIN`、保存側を逆にした `RIGHT OUTER JOIN`、結合条件を失う `CROSS JOIN` のように、結合方式という同じ判断軸で比較させます。

3. **無関係な埋め草を禁止する**
   - 画面設定、背景色、キーボード配列、CPU温度、ファイル名、壁紙など、設問の判断軸と関係しない語を「明らかな誤答」として置きません。
   - 正答以外を読まなくても消去法だけで解ける選択肢セットを作りません。

4. **誇張表現を正誤の目印にしない**
   - 「絶対」「何もしない」「一切不要」「必ず全部」のような極端な表現だけを理由に落とせる選択肢を避けます。
   - その表現自体を論点として問う場合を除き、誤答は現実にあり得る設定・設計・運用上の誤りにします。

5. **誤答理由は設問の条件へ結び付ける**
   - `不正解です`、`関係ありません` だけで終わらせません。
   - どの条件を満たさないか、どの概念と取り違えているか、どの計算・追跡ミスかを具体的に書きます。

6. **計算問題は実際の誤計算から誤答を作る**
   - 単純なランダム値ではなく、符号の扱い、分母分子の逆転、境界値の除外忘れ、1回分の数え落としなど、追跡可能な誤りから作ります。

7. **プログラム問題は同じ返却型で、追跡ミスを反映する**
   - 数値を返す問題に変数名や「未定義」を混ぜるなど、型だけで除外できる選択肢を置きません。
   - 添字、更新順、ループ回数、条件分岐、初期値などの具体的な読み違いを誤答へ反映します。

8. **用語問題は近接概念から誤答を選ぶ**
   - 同じ分野に属するというだけで無関係な語を機械的に選びません。
   - 役割・階層・目的・処理段階が近く、試験で混同しやすい概念を優先します。
   - 自動生成では `src/content/questions/concept-confusion-groups.ts` に明示した混同候補グループ内だけから候補を選び、その中で意味上の近さを使って3件を決めます。
   - グループだけでは比較軸が揃わない用語は `src/content/questions/concept-distractor-overrides.ts` で3件を明示します。
   - 配列位置の固定オフセットや、同一分野全体からの無制限な自動抽出だけを根拠に誤答を選ぶことは禁止します。混同候補グループも明示オーバーライドもない用語は生成時エラーにします。

9. **正答位置・既存ID・学習履歴互換性を維持する**
   - 品質修正では既存IDと正答インデックスを原則維持します。
   - 問題文自体を修正する必要がある場合も、過去の学習履歴を壊さないようIDを維持し、正答位置を変えない設計を優先します。

## レビュー手順

問題追加・修正時は、正答を見る前に4択だけを読んで次を確認します。

- 正答だけが具体的・長文・専門的になっていないか
- 3つの誤答すべてについて、学習者が選ぶ具体的な誤解を説明できるか
- 一つでも設問と無関係な埋め草がないか
- 選択肢の型・粒度・文体がおおむねそろっているか
- 誤答理由が設問の条件へ直接結び付いているか

一つでも満たさなければ、その問題は未完成として修正します。

## 自動検査

自動テストでは最低限、317問全体に対して次を確認します。

- 既知の無関係な埋め草表現が存在しないこと
- 選択肢の重複がないこと
- 全選択肢に具体的な理由があること
- 基本問題と通常問題の両方が監査対象に含まれること
- 用語問題は混同候補グループまたは明示オーバーライドを持つこと
- 代表的な用語問題で、近接概念の誤答が選ばれていること
- 過去に発生した品質不良問題を回帰テストで固定すること

自動検査は人間の内容レビューを置き換えません。テストを通過しても、正答だけが目立つ、誤答が現実的でない、比較軸がずれている問題は修正対象です。
