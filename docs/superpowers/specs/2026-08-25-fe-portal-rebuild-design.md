# FE学習ポータル全面再構成 — デザイン仕様

## 目的

SAA-C03学習ポータルで有効だった「目的ナビ、学習パス、教材サイドバー、本文内の図、問題演習への接続」をFE用に再構成する。SAAの文章・問題・画像は複製せず、FEの科目A・科目B向けコンテンツだけを表示する。

## 画面構造

すべての主要画面で次の共通シェルを使う。

1. 緑系グラデーションのサイトヘッダー（サイト名、試験構成、問題数）
2. stickyな目的ナビ（教材、問題演習、弱点補強、模試、学習記録）
3. 最大幅のポータル本文

トップは `この順番で進める`、`問題演習`、`図解画像一覧` の順で表示する。教材画面は `portal-layout` とし、左に検索可能な章一覧、右に現在章のMarkdown風本文を置く。

## 教材本文

教材の章本文は、要約、章内リンク、節見出し、段落、判断軸、混同注意、試験の注意点の順に表示する。説明図は章の先頭に固定せず、関連する節の途中にインラインfigureとして埋め込む。画像はクリックで拡大でき、altと説明文を持つ。

## 導線

- 共通目的ナビは全画面から利用できる。
- 教材本文の冒頭と末尾に、この章の問題、弱点補強、学習記録へのリンクを置く。
- 問題回答後は関連教材、弱点復習、学習記録へ移動できる。
- 模試終了後は誤答復習と直前確認へ移動できる。

## 受入条件

- 旧FE専用の暗色ヒーロー画面を廃止し、SAAと同じ情報設計のポータル構造へする。
- ネットワーク章ではDNS・TTL、TCP・UDP、サブネットの図が各節の途中に表示される。
- セキュリティ章では認証・アクセス制御の図が認証節の途中に表示される。
- 主要画面すべてで目的ナビから問題演習、弱点補強、模試、学習記録へ遷移できる。
- 375px相当でも目的ナビ、章一覧、本文、画像、次の導線が横にはみ出さない。
- `npm test`、`npm run typecheck`、`npm run build`、`npm run verify:ai` が成功する。
