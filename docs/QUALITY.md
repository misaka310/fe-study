# Quality

このプロジェクトでは、教材の内容量だけでなく、**問題データの整合性・学習状態の互換性・ブラウザ導線・公開リポジトリとしての再現性**を品質対象にしています。

## 自動検証

通常の変更で実行する基準です。

```bash
npm run lint
npm test
npm run typecheck
npm run build
```

ブラウザ導線を変更した場合は、追加で次を実行します。

```bash
npm run test:e2e
```

## テストしている主な領域

| 領域 | 主な検証 |
| --- | --- |
| 問題データ | 問題数、一意ID、選択肢、正答、解説、選択肢別理由 |
| 問題品質 | 露骨な誤答ヒント、重複・類似、近接概念の誤答、科目Bの構成 |
| 科目A補強 | 基本問題160問、セット構成、重要語・公開問題由来の論点カバレッジ |
| 解説画像 | 全465問との一対一対応、メタデータ、読み込み失敗時のフォールバック |
| 学習状態 | 回答履歴、弱点、模試状態、保存・復元、JSONバックアップ |
| UI | 教材、問題演習、模試、学習記録、用語チップ |
| E2E | 章切替、URL履歴、戻る／進む、再開、レスポンシブ表示 |
| 公開品質 | READMEの必須情報、端末固有パスや内部運用情報の混入防止 |

## 現在の教材・問題構成

- 教材: 12章
- 通常問題: 305問
  - 科目A: 165問
  - 科目B: 140問
    - 基礎: 100問
    - 本番レベル: 40問
- 科目A基本問題: 160問（20問 × 8セット）
- 合計: 465問
- 問題解説画像: 465問と一対一で対応

問題数など機械的に導出できる値は、画面コンポーネントへ別の固定値として持たせず、正本データから算出します。

## 手動確認が必要なもの

自動テストだけでは判断しきれない次の点は、関連変更時に実ブラウザでも確認します。

- 問題文・選択肢・解説が自然な日本語で、正答を不自然に誘導していないこと
- 教材図・問題解説図が内容理解に寄与し、文字化けや意味不明な図になっていないこと
- デスクトップ／モバイルで主要操作が迷わず使えること
- キーボード操作とフォーカス表示が破綻していないこと
- エラー時に学習フローへ戻れること

## 公開リポジトリの受入基準

- クローン後、Firebase設定なしでも `npm ci`、テスト、build、ローカル起動ができる。
- READMEから目的、技術構成、起動、検証、設計、ライセンスへ到達できる。
- 一般公開ドキュメントにcredential、個人端末の絶対パス、過去のdeployment IDを残さない。
- 非公式教材であること、公式採点を再現しないこと、IPA公式情報へのリンクを明記する。
