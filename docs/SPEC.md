# 基本情報技術者 合格ナビ — Product Specification

## 1. 元の目的

ITパスポート相当の基礎知識を持つ学習者が、基本情報技術者試験（FE）の科目Aと科目Bを体系的に学び、本番形式の演習と弱点補強を通して合格水準へ到達できる日本語教材・問題集・模擬試験サイトを提供する。

参照品質は `misaka310/aws-saa-c03-study` の教材、問題演習、弱点補強、模試、詳細解説、学習履歴、図解、検証、Sites公開を一体化した構成とし、基本情報の広い試験範囲に合わせて内容を再設計する。参照リポジトリの文章、問題、画像、コードは複製せず、構成上の品質基準だけを参考にする。

## 2. 期待する最終結果

- GitHub上に `fe-study` というPrivateリポジトリが作成され、検証済みソースが保存されている。
- OpenAI Sitesに所有者限定でデプロイされ、発行されたURLからブラウザだけで利用できる。
- 教材は約12章で、科目Aのテクノロジ・マネジメント・ストラテジと、科目Bのアルゴリズム・擬似言語・情報セキュリティをカバーする。
- 独自作成問題を合計215問以上収録し、科目Aと科目Bの双方を十分に演習できる。
- ユーザー提供の追加教材から、既存問題と過度に重複しない問題だけを選別して統合し、採用問題は総合解説と4択それぞれの具体的な採否理由を保持する。
- 本番と同じ科目A 60問・90分、科目B 20問・100分の模擬試験を開始できる。
- すべての問題に正答、総合解説、全選択肢それぞれの採否理由、関連分野・論点を持たせる。
- 全問、科目別、分野別、未回答、誤答、弱点補強、模試の各モードを利用できる。
- 回答履歴、正答率、分野別成績、累積誤答をブラウザへ保存し、JSONで書き出し・復元できる。
- IPAのシラバスVer.9.2、試験要綱、2023〜2026年度公開問題への公式リンクをまとめる。公開問題本文は転載しない。
- READMEから公開サイト、教材、問題演習、模試、弱点補強へ直接移動できる。

### 教材構成

1. 学習の始め方と合格ロードマップ
2. 基礎理論・離散数学・情報表現
3. コンピュータ構成要素・ハードウェア
4. OS・ソフトウェア・開発環境
5. データ構造とアルゴリズム
6. データベース
7. ネットワーク
8. 情報セキュリティ
9. システム開発・ソフトウェア設計
10. プロジェクト・サービスマネジメント
11. ストラテジ・企業活動・法務
12. 科目B攻略、試験戦略、直前確認、図解復習

### 問題構成

- 合計215問以上とし、科目Aは165問以上、科目Bは50問以上を最低条件とする。
- 科目Aは四肢択一を基本とし、計算、用語理解、設計判断を偏りなく含める。
- 科目Bは擬似言語読解、配列、探索、整列、スタック・キュー、再帰、計算量、プログラム修正、情報セキュリティ事例を含める。
- 同一テンプレートの数値や名詞だけを変えた水増し問題を禁止する。
- 模試は問題バンクから科目・分野配分を保って抽出し、再作成できる。
- 合否表示は公式のIRT得点を偽装せず、正答率による学習上の目安であることを明記する。

### 完成扱いにしないもの

- 問題数だけを満たし、選択肢別解説や科目Bの読解過程が不足している状態。
- 教材の章題だけ、問題雛形、未実装項目、サンプル、ダミー、重複問題が残っている状態。
- 科目Aだけ、または科目Bだけしか実用水準へ達していない状態。
- buildや単体テストだけ成功し、学習開始から模試・復習までの実ユーザー導線を確認していない状態。
- ローカル開発サーバーだけが動き、GitHub PrivateリポジトリまたはSites公開が未完了の状態。
- IPA公開問題を独自問題として転載した状態。
- 古いキャッシュ、別プロセス、fallback表示を正常な公開サイトと誤認した状態。

## 3. ユーザー操作・導線

### Happy Path

1. ユーザーがSitesのトップページを開き、「学習を始める」を選ぶ。
2. 学習ロードマップで現在地を確認し、章を順番に読み、章末の関連問題へ進む。
3. 問題を選択して解答し、正誤、決め手、全選択肢の理由、関連教材を確認する。
4. 全問・分野別演習を進め、分野別成績と弱点一覧を確認する。
5. 「弱点補強」で累積誤答の多い論点を解き直す。
6. 科目A模試と科目B模試を本番と同じ問題数・制限時間で受ける。
7. 模試結果から誤答問題と関連教材へ戻り、直前確認で未解決論点をなくす。

### エラー時

- 教材・問題データを読み込めない場合は、空画面にせず再読み込み案内を表示する。
- 未回答で解答操作をした場合は、選択を求める状態を画面上に示す。
- 保存データが壊れている場合は、利用可能な履歴だけを正規化し、復元できない場合は理由と安全なリセット手段を示す。
- JSON復元で形式が不正な場合は既存履歴を上書きせず、失敗理由と再選択方法を示す。
- 模試中に再読み込みしても、現在の問題順、位置、開始時刻を復元する。
- 時間切れ時は回答受付を終了し、結果と復習導線を表示する。
- 問題が存在しないフィルターでは、別モードへ戻る操作を表示する。

## 4. 制約条件

- 2026年8月時点のIPA公式情報と基本情報技術者試験シラバスVer.9.2を基準にする。
- 2027年度予定の制度見直しでもFEは科目A 60問・90分、科目B 20問・100分を継続するというIPA公表内容を反映する。
- 合格基準は両科目とも評価点600点以上だが、実際のIRT採点は再現できないためサイト内の正答率を公式評価点として表示しない。
- 日本語、レスポンシブ、キーボード操作、基本的なスクリーンリーダー利用に対応する。
- 学習履歴はlocalStorageへ保存し、認証、外部データベース、個人情報収集を行わない。
- 依存関係を最小化し、Cloudflare Worker互換のSitesビルドを使う。
- 画像は必要な図解だけに限定し、第三者画像の無断転載やモデル生成SVGを使わない。
- GitHubリポジトリはPrivate、Sitesは所有者限定アクセスを既定とする。

## 5. 非目標

- 合格を保証する法的・教育的サービス、公式採点の再現、受験申込み代行。
- IPA公開問題本文の転載、他社教材・問題・画像の複製。
- ユーザーアカウント、クラウド同期、ランキング、課金、SNS機能。
- AIによる自動採点・質問応答、講師向け管理画面。
- ITパスポート範囲をゼロから網羅する入門講座。

## 7. 検証方法

- 新規リポジトリ仕様Gate: `python.exe C:\00_dev\.agents\maintenance\validate-new-repository-spec.py --repo .`
- データ検証: 問題数、ID、科目・分野、正答index、選択肢別理由、類似度、模試blueprint、教材リンク、公式URLをNodeテストで検査する。
- 状態検証: 回答記録、累積誤答、弱点抽出、模試復元、バックアップ書き出し・復元・不正入力拒否を単体テストする。
- ソース検証: TypeScript型検査、lint、production buildを実行する。
- ユーザー導線: トップ→教材→関連問題→解答→弱点補強→模試→結果→教材復帰をE2Eで確認する。
- レスポンシブ・アクセシビリティ: 主要viewport、フォーカス順、ラベル、aria-live、色以外の正誤表現を検査する。
- 公開検証: デプロイ後URLへ別リクエストを送り、トップ、教材、問題演習、模試入口がエラーなく応答することを確認する。
- Git検証: リモートvisibilityがPrivateであること、push済みHEADとローカルHEADが一致することをGitHub metadataで確認する。

## 8. 主要アーキテクチャ

- OpenAI Sites標準scaffoldを基盤にした単一の学習ポータルとする。
- 教材、問題、用語、試験blueprintを静的TypeScriptデータとして管理し、UIから分離する。
- 学習状態モジュールが回答履歴、模試状態、弱点集計、backup schemaを所有する。
- URL queryで教材、演習モード、科目、分野を直接開けるようにし、共有・再読み込みに耐える。
- サーバー永続化は使わず、配信時の静的データとブラウザlocalStorageだけで完結する。
- 問題品質は実行時UIではなく決定論的テストで検証する。
